## Áreas de interés

- **People analytics y experiencia del empleado:** medición del clima laboral y propuestas de mejora basadas en datos.
- **Automatización de procesos:** reducción de tareas manuales en operaciones administrativas y de recursos humanos.
- **Analítica de datos y dashboards:** diseño de sistemas de control y visualización para la toma de decisiones.
- **NLP aplicado a selección de personal:** emparejamiento semántico entre currículums y puestos.
- **Arquitectura de software y gestión de proyectos.**
